PROJET AMAZON SCRAPER

Ce projet permet d'apprendre le scraping avec Python et Selenium.

Technologies utilisées :
- Python
- Selenium
- SQLite
- HTML
- CSS

Organisation :
- controllers : gère les actions
- models : gère les données
- scraper : récupère les informations
- views : affiche les résultats
- data/images : stocke les images
- exports : contient les fichiers CSV

Pour lancer le programme :
python main.py

Le projet commence par tester Selenium sur une page de démonstration.
La collecte des produits et le téléchargement des images seront ajoutés
progressivement.

Respecter les conditions d'accès des sites utilisés.
